# Harness logo

JiuwenSwarm uses its project logo, which is not available in Lobe Icons:
https://github.com/openJiuwen-ai/jiuwenswarm/blob/main/docs/assets/images/logo.svg

Codex, Claude Code, OpenCode and model brand glyphs are imported directly from
the pinned `@lobehub/icons-static-svg` npm dependency. No copies of those SVGs
are stored in this repository. Vite bundles the referenced assets for offline use.
